# Automação de Cotação de Moedas com Airtable 💱

Projeto em Python que busca cotações em tempo real (Dólar, Euro, Iene e Bitcoin) e atualiza automaticamente uma base de dados no Airtable.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **APIs:** AwesomeAPI & CoinGecko
- **Integração:** `pyairtable`
- **Ambiente:** Google Colab

## 🚀 Como Executar
1. Instale a biblioteca: `pip install pyairtable`
2. Adicione suas credenciais do Airtable (`AIRTABLE_TOKEN` e `BASE_ID`).
3. Execute o script `atualizar_moedas.py`.
